# Executive Dashboard: Business Intelligence & Sales Analysis (Amazon Data)

## 📊 Dashboard Preview
![Amazon Sales Dashboard](dashboard%20example%20HL.png)

## 🎯 Project Objective
The purpose of this project is to analyze a massive Amazon Sales dataset to identify the Logistics Waste Rate generated by order returns and packaging inefficiencies, transforming raw operational data into strategic financial and environmental insights.

## 🛠️ Tech Stack & Skills Demonstrated
* **Database & Extraction:** SQL Server (Local data integration and table structuring).
* **ETL & Data Modeling:** Power Query (Data cleaning, null handling, and Star Schema design).
* **Analytics & Metrics:** Advanced DAX formulas and Time Intelligence functions.
* **Automation:** AI-assisted prompt engineering for efficient SQL script generation.

## 📈 Key Metrics Explored
* **Total Revenue:** $18.65M managed across 37K total processed orders.
* **Distribution Efficiency:** Comparative analysis between Merchant-fulfilled orders and Amazon's internal logistics to detect resource leaks.
